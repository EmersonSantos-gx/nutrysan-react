# Nutrysan Consultoria Sanitária — Landing Page (React + JavaScript)

Vite + React 18. Mobile first.

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # gera a pasta dist/
```

- Textos, contatos e listas: `src/data.js`
- Seções e componentes: `src/App.jsx`
- Estilos (paleta, tipografia, responsivo): `src/styles.css`
- Logos: `src/assets/`
